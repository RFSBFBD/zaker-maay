# قرارات معمارية أولية

1. Supabase Auth للمصادقة، وNeon PostgreSQL لبيانات التطبيق. لا تستخدم Supabase Database في هذا التصميم.
2. كل مفاتيح مزودي AI والتخزين موجودة في backend.
3. كل صلاحية مادة تتحقق server-side في كل request.
4. لا توجد معالجة تلقائية مضمونة لفيديو YouTube بمجرد الرابط؛ يعتمد ذلك على مصدر transcript مصرح ومتاح.
5. الملفات والصوت يعالجان ضمن حدود الحجم والنوع والحصة التي تدعمها الخدمات الحالية.
6. RAG لا يُعتبر معزولًا بمجرد system prompt؛ يجب تطبيق subject filter في retrieval والاستعلامات.
7. البدء بـ architecture بسيطة، وإضافة queue/vector extension/agent framework عند الحاجة المثبتة فقط.
8. لا يُنشر التطبيق أو تُنفذ عمليات مدمرة دون موافقة صريحة.
