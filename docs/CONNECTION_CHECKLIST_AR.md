# قائمة القيم المطلوبة للربط

أدخل القيم بنفسك داخل ملفات البيئة المحلية. لا تلصق الأسرار في المحادثة ولا تحفظها في Git.

## Supabase Auth
- Project URL.
- Publishable key للواجهة فقط.
- طريقة التحقق من JWT في الـ backend: JWKS/issuer/audience بحسب إعداد المشروع والنسخة المعتمدة.
- تفعيل مزود Google اختياريًا من لوحة Supabase، وإضافة Redirect URLs محلية وإنتاجية عند الحاجة.

## Neon
- Connection string لقاعدة PostgreSQL، مع SSL.
- تأكد أن المستخدم لديه الصلاحيات اللازمة للتطبيق وعمليات migrations.
- لا تستخدم connection string في الواجهة الأمامية.

## Cloudinary
- Cloud name.
- API key.
- API secret (backend فقط).
- مجلد التخزين المقترح: `study-platform`.
- يجب أن يوقّع الخادم معاملات الرفع، ثم يتحقق من ملكية المورد ونوعه وحجمه بعد الرفع.

## Gemini
- API key.
- اسم نموذج توليد نص مدعوم حاليًا.
- نموذج embeddings مدعوم حاليًا إن استُخدم.
- تحقّق من الوثائق وحدود الحصة الحالية قبل اختيار النموذج؛ لا تفترض أن كل نموذج يدعم الصوت أو embeddings أو أن الحصة غير محدودة.

## قبل أول تشغيل
- [ ] نسخ `frontend/.env.local.example` إلى `frontend/.env.local`.
- [ ] نسخ `backend/.env.example` إلى `backend/.env`.
- [ ] استبدال قيم `YOUR_*` بالقيم الصحيحة.
- [ ] عدم إدراج أي سر في `NEXT_PUBLIC_*`.
- [ ] التأكد من أن ملفات البيئة مستثناة من Git.
- [ ] تشغيل فحص إعدادات البيئة من backend دون طباعة القيم السرية.
- [ ] تشغيل اختبارات الاتصال كل خدمة على حدة.
