What Is a Constructor?
A constructor is a special member function that is called automatically 
when an object is created. 
 
1.
A constructor must have the same name as the class itself.
2.
Constructors do not have a return type.

Destructor
A destructor is a special method that is automatically called when an object life 
time is ended. The most common use of destructors is to deallocate memory that 
was allocated for the object by the constructor
